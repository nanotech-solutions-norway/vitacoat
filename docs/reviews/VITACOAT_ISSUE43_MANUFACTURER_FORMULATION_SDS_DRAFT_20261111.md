**4. TDS, installation and scope**
- Release current manufacturer-approved technical data sheet, application instructions/IFU, cleaning/degreasing, substrate compatibility, application quantity, film thickness, curing time, ambient constraints, service/maintenance cleaning compatibility and operator PPE/ventilation.
